Keamanan & Privasi Data

Data kesehatan Anda dilindungi dengan standar keamanan enterprise

Autentikasi & Akses
  • 2FA — Google Authenticator
  • Password Policy — Minimal 8 karakter, huruf besar/kecil, angka, simbol
  • RBAC — Role-Based Access Control (Admin, Dokter, Pasien)
  • New IP Detection — Deteksi login dari perangkat baru
  • Account Lockout — 5x gagal = terkunci 15 menit
Perlindungan Data
  • AES-256 — Enkripsi file medis
  • CSRF Protection — Token pada setiap form
  • XSS Sanitization — Bleach + Jinja2 autoescaping
  • SQL Injection Prevention — SQLAlchemy ORM parameterized queries
  • Input Validation — WTForms dengan validasi ketat
Monitoring & Audit
  • Audit Logging — Semua aktivitas tercatat
  • Suspicious IP Detection — Deteksi & blokir IP mencurigakan
  • Rate Limiting — 10x/menit login, 3x/menit register
  • Session Timeout — 30 menit inactivity
  • Security Headers — CSP, HSTS, X-Frame-Options, dll
